# 🇵🇰 Pakistan Data Atlas

An interactive data visualization platform transforming Pakistan's socio-economic datasets into compelling visual narratives. Built with React, TypeScript, and Tailwind CSS.

## Overview

Pakistan Data Atlas provides comprehensive dashboards covering four key domains:

- **📚 Education** — Literacy rates, enrollment trends, infrastructure by province
- **🗳️ Elections** — Party performance, seat distribution, voter turnout history
- **👥 Population** — Demographics, age distribution, urbanization trends
- **💰 Economy** — GDP growth, inflation, provincial economic contribution

## Features

- **Interactive Maps** — Explore district-level data on a clickable Pakistan map
- **Bilingual Support** — Full English/Urdu interface with RTL layout
- **Data Export** — CSV and PDF reports in English, Urdu, or bilingual formats
- **Print Dashboards** — Print-optimized views for individual or all domains combined
- **Time Filtering** — Slider-based historical data exploration
- **Province Comparison** — Side-by-side regional analysis
- **Dark/Light Mode** — Theme toggle with consistent design tokens
- **Responsive Design** — Mobile-first layout across all screen sizes

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | React 18 + TypeScript |
| Build | Vite |
| Styling | Tailwind CSS + shadcn/ui |
| Charts | Recharts |
| Animation | Framer Motion |
| PDF Export | jsPDF + jspdf-autotable |
| Routing | React Router v6 |

## Getting Started

```bash
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project
cd pakistan-data-atlas

# Install dependencies
npm install

# Start development server
npm run dev
```
